## This is a simple python program
`sys_monitor.py`: A custom, lightweight SRE diagnostic tool that queries Linux `/proc` systems to audit hard drive space, RAM usage percentages, and active CPU averages.

---
## 🛠️ How to Run Your System Monitor:
To execute a live diagnostic audit of your machine's resources, run this command in your terminal:
```bash
python3 sys_monitor.py
