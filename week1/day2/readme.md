# Week 1 · Day 2: Control Flow & Loops in Python

Today, I mastered how Python makes logical decisions using conditionals and executes repeated tasks using loops.

## What I Learned:
* **Control Flow:** Using `if`, `elif`, and `else` to route code execution paths.
* **For Loops:** Iterating over a set range of numbers (e.g., `range(1, 11)`).
* **While Loops:** Iterating dynamically as long as a condition is True.
* **SRE Warning:** Learned how infinite loops lock up 100% of a server's CPU, and how to write clear exit parameters.

## Scripts Included:
1. `NumberGuesser.py`: An interactive game using Python's random library and conditional boundaries.
2. `table.py`: Generates the multiplication table of any user-inputted number.
3. `countDown.py`: A server deployment countdown utility utilizing a `while` loop.
